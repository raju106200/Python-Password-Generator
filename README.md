# 🔐 Python Password Generator

## 📌 About the Project
Python Password Generator is a simple beginner-friendly mini project that generates random and secure passwords using Python.

It uses letters, numbers, and special characters to create random passwords.

## ✨ Features
- Generate random passwords.
- Choose your desired password length.
- Includes uppercase and lowercase letters.
- Includes numbers (0–9).
- Includes special characters (@, #, $, etc.).
- Simple and easy-to-use program.

## 🛠️ Technologies Used
- Python 3
- Random Module
- String Module

## 💻 Source Code
The project is created using basic Python concepts:
- Variables
- User Input
- For Loop
- Random Module
- String Module

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the following command:

```bash
python password_generator.py
```

4. Enter your desired password length.
5. Your random password will be generated!

## 📷 Sample Output

```text
===== PASSWORD GENERATOR =====

Enter password length: 10

Your Generated Password is: A@7kP#2mQ!
```
